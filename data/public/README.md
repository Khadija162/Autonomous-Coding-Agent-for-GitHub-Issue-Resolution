# Open evaluation fixture

The included issue descriptions and miniature Python repository are original, openly reusable **CC0 1.0** teaching fixtures. They contain no real GitHub user data or private code. This is not the [SWE-bench](https://www.swebench.com/) benchmark.

For more realistic evaluation, use published SWE-bench issue metadata, respecting each original codebase's license and executing workloads inside strongly isolated disposable infrastructure.
